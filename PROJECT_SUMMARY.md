## 🎯 How to Get Started

### 1. Quick View (1 minute)
```bash
1. Double-click index.html
2. Website opens in browser
3. Done! 🎉
```

### 2. Setup for Development (5 minutes)
```bash
# Option A: VS Code + Live Server extension
1. Install "Live Server" extension
2. Right-click index.html
3. Select "Open with Live Server"

# Option B: Python
python -m http.server 8000
# Then open http://localhost:8000

# Option C: PHP
php -S localhost:8000
# Then open http://localhost:8000
```

## 🐛 Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Images not loading | Check image URLs, use full paths |
| Form not sending | Verify WhatsApp number in script.js |
| Mobile menu not working | Check browser console for JS errors |
| Colors not changing | Clear browser cache (Ctrl+Shift+Del) |
| Responsive not working | Verify viewport meta tag in <head> |
| Slow loading | Compress images, check CDN status |
